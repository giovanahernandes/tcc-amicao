## Como visualizar o projeto

O AmiCão foi desenvolvido utilizando **HTML, CSS e JavaScript**, sem a utilização de banco de dados.

### Passo a passo

1. Faça o download ou clone este repositório.
2. Mantenha a estrutura de pastas do projeto original.
3. Abra a pasta do projeto.
4. Localize o arquivo `index.html`.
5. Abra o arquivo `index.html` em um navegador, como Google Chrome, Microsoft Edge ou Firefox.
6. Navegue pelo site utilizando os menus e botões disponíveis.

### Tecnologias utilizadas

* HTML5
* CSS3
* JavaScript
